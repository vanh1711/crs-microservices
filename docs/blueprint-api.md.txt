1. api-gateway (cổng 8080 - Cổng tiếp nhận và định tuyến tập trung)
- /api/auth/** -> Chuyển tiếp tới auth-service:8081 (/auth/**)
- /api/courses -> Chuyển tiếp tới course-service:8082 (/courses)
- /api/courses/** -> Chuyển tiếp tới course-service:8082 (/courses/**)
- /api/registrations -> Chuyển tiếp tới registration-service:8083 (/registrations)
- /api/registrations/** -> Chuyển tiếp tới registration-service:8083 (/registrations/**)
- /api/public/courses -> Chuyển tiếp tới course-service:8082 (/courses, xác thực X-API-KEY)
- AuthHeaderFilter: Kiểm tra Bearer JWT với các route bảo vệ, bỏ qua Login và GET /api/courses

2. auth-service (cổng 8081, tiền tố Gateway: /api/auth)
- POST /auth/login : Đăng nhập tài khoản admin/student, trả về JWT Token

3. course-service (cổng 8082, tiền tố Gateway: /api/courses)
- GET /courses : Danh sách môn học, tìm kiếm theo keyword, phân trang (page, size)
- GET /courses/{id} : Xem chi tiết một môn học
- POST /courses : Thêm môn học mới (yêu cầu ROLE_ADMIN & Bearer JWT)
- PUT /courses/{id} : Cập nhật thông tin môn học (yêu cầu ROLE_ADMIN & Bearer JWT)
- DELETE /courses/{id} : Xóa môn học theo ID (yêu cầu ROLE_ADMIN & Bearer JWT)
- PATCH /internal/courses/{id}/reserve-seat : Giữ chỗ, trừ số lượng chỗ trống (gọi nội bộ)
- PATCH /internal/courses/{id}/release-seat : Nhả chỗ, hoàn lại chỗ trống khi hủy (gọi nội bộ)
- GET /api/public/courses : API cung cấp cho đối tác (yêu cầu X-API-KEY)

4. registration-service (cổng 8083, tiền tố Gateway: /api/registrations)
- POST /registrations : Đăng ký môn học (gọi sang course-service để giữ chỗ)
- GET /registrations/student/{studentId} : Danh sách môn học đã đăng ký theo sinh viên

5. crs-frontend (cổng 5174/5173 - Giao diện người dùng)
- Axios Client: Cấu hình baseURL = http://localhost:8080, tự động gắn `Authorization: Bearer <crs_token>`
- GET /api/courses : Tra cứu danh sách môn học kèm keyword, page, size (Hook useCourses)
- POST /api/courses : Thêm môn học mới qua CourseForm (Controlled Component)
- PUT /api/courses/{id} : Chỉnh sửa môn học qua CourseForm
- DELETE /api/courses/{id} : Xóa môn học có hộp thoại xác nhận (window.confirm)
- POST /api/auth/login : Gửi thông tin đăng nhập và lưu JWT Token vào localStorage
- POST /api/registrations : Gửi yêu cầu đăng ký học phần kèm Bearer JWT
- Quản lý 4 trạng thái giao diện: Loading (Skeleton), Success, Empty, Error (kèm nút Thử lại)
- Đồng bộ dữ liệu: Tự động gọi `refetch()` cập nhật lại danh sách ngay sau khi Thêm/Sửa/Xóa
